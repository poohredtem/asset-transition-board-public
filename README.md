# 資産推移ボード 無料版

毎月の資産推移を記録して、グラフと記事用画像を作るための単一HTMLツールです。
ブラウザだけで動き、データは端末の中（localStorage）にだけ保存されます。外部サーバーへの送信は一切しません。

## 無料版でできること

- 資産推移の記録（全資産の手入力／楽天証券CSVの取込・突合せ）
- 資産推移グラフの表示
- 記事用画像①「資産推移グラフ」（1200×675）の書き出し
- JSONバックアップの書き出し／読み込み

最初に入っている記録はサンプル数字です。自分の記録に置き換えて使ってください。

## 完全版について

FIRE分析（シミュレーター／モンテカルロ／資産寿命）・配当管理・記事用画像②③は完全版の機能です（2026年12月発売予定）。

## 使い方

`index.html` をブラウザで開くだけで使えます（iPhone Safari想定）。
このページ（GitHub Pages）から直接使うことも、ファイルをダウンロードして端末に保存して使うこともできます。
